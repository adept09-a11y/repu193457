# VoiceChannelNotify - Vencord Plugin

Плагин для Vencord, который отправляет уведомления в Telegram, когда пользователи заходят в выбранные голосовые каналы Discord.

## Функционал

- 🎤 Отслеживание входа пользователей в выбранные голосовые каналы
- 📱 Отправка уведомлений через Telegram бота
- ⚙️ Гибкая настройка monitored каналов
- 🔐 Безопасное хранение настроек

## Настройки

### 1. Telegram Bot Token
Токен вашего Telegram бота. Получить можно у [@BotFather](https://t.me/BotFather):
1. Откройте @BotFather в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен (выглядит как `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 2. Telegram Chat ID
ID пользователя или чата, куда будут приходить уведомления.

**Как узнать свой Chat ID:**
1. Запустите созданного бота (нажмите Start)
2. Отправьте боту любое сообщение
3. Перейдите в браузере по ссылке: `https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates`
4. Найдите в ответе `"chat":{"id":123456789,...}` - это и есть ваш Chat ID

### 3. Monitored Channels (Отслеживаемые каналы)
Список ID голосовых каналов для отслеживания.

**Как узнать ID канала:**
1. Включите режим разработчика в Discord (Настройки → Дополнительно → Режим разработчика)
2. Кликните правой кнопкой мыши по голосовому каналу
3. Выберите "Копировать ID" (Copy ID)
4. Вставьте ID в поле настройки и нажмите "Add"

## Установка

### Через Vencord
1. Скопируйте ссылку на репозиторий или прямую ссылку на файлы плагина
2. Откройте настройки Vencord (Vencord → Plugins)
3. Нажмите "Add Plugin" и вставьте ссылку
4. Включите плагин в списке
5. Настройте параметры в разделе настроек плагина

### Вручную
1. Скопируйте файлы `index.tsx` и `vendetta_manifest.json` в папку плагинов Vencord
2. Перезагрузите Discord
3. Включите плагин в настройках Vencord

## Использование

1. Откройте настройки плагина в Vencord
2. Введите токен Telegram бота
3. Введите ваш Telegram Chat ID
4. Добавьте ID голосовых каналов для отслеживания
5. Сохраните настройки

Теперь вы будете получать уведомления в Telegram каждый раз, когда кто-то зайдёт в отслеживаемые голосовые каналы.

## Пример уведомления

```
🎤 User Joined Voice Channel

👤 User: Username
📢 Channel: General
🏰 Server: My Server
⏰ Time: 24.04.2024 15:30:00
```

## Требования

- Vencord версии 1.0.0 или выше
- Активный Telegram аккаунт
- Созданный Telegram бот
