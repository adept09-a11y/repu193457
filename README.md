# Discord to Telegram Notification Forwarder

Приложение для пересылки уведомлений из Discord в Telegram с использованием Userbot (discord.py self-bot).

## 📋 Требования

- Python 3.8+
- Аккаунт Discord (для Userbot)
- Telegram Bot Token (для отправки сообщений)
- Telegram Chat ID (куда отправлять уведомления)

## 🔧 Установка

1. Клонируйте репозиторий или скопируйте файлы проекта в папку
2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` на основе `.env.sample` и заполните токенами:
```bash
cp .env.sample .env
# Отредактируйте .env и добавьте ваши токены
```

4. Запустите приложение:
```bash
python main.py
```

## 🎯 Настройка Discord Intents

Для работы приложения необходимо включить следующие intents в Discord Developer Portal:

### Для бота (если используете обычного бота):
1. Перейдите на https://discord.com/developers/applications
2. Выберите ваше приложение
3. Перейдите во вкладку "Bot"
4. В разделе "Privileged Gateway Intents" включите:
   - **Message Content Intent** - необходим для чтения содержимого сообщений
   - **Server Members Intent** - для получения информации о пользователях
   - **Presence Intent** - для отслеживания статуса пользователей

### Для Userbot (самобот):
⚠️ **Важно:** Использование самоботов (userbots) нарушает условия использования Discord и может привести к блокировке аккаунта. Используйте на свой страх и риск.

Для userbot intents настраиваются автоматически, но для чтения сообщений на некоторых серверах может потребоваться:
- Быть участником сервера
- Иметь права на чтение сообщений в каналах

## 📝 Получение токенов

### Discord Token (Userbot):
1. Откройте браузер и войдите в Discord
2. Откройте DevTools (F12)
3. Перейдите на вкладку Network
4. Обновите страницу
5. Найдите запрос к `api.discord.com`
6. В заголовках найдите `Authorization` - это ваш токен

⚠️ **Никогда не передавайте свой токен никому!**

### Telegram Bot Token:
1. Создайте бота через @BotFather в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям
4. Полученный токен сохраните в `.env`

### Telegram Chat ID:
1. Добавьте бота в чат/канал (или используйте личный чат)
2. Отправьте сообщение в чат
3. Используйте @getmyid_bot или отправьте запрос к API:
   ```
   https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates
   ```
4. Найдите `chat.id` в ответе

## 🎮 Использование

### Основное окно:
- **Telegram Chat ID**: Введите ID чата для получения уведомлений
- **Управление пользователями**: Добавляйте/удаляйте Discord ID пользователей для отслеживания
- **Управление серверами**: Добавляйте/удаляйте Guild ID серверов для отслеживания
- **Фильтры**: Опция фильтрации по упоминаниям и ключевым словам

### Кнопки:
- **Start Bot**: Запустить прослушивание Discord
- **Stop Bot**: Остановить бота
- **Сохранить конфиг**: Сохранить настройки в config.json
- **Просмотр логов**: Открыть окно с логами

### Отслеживаемые события:
1. **Новые сообщения** - пересылка текстовых сообщений от отслеживаемых пользователей
2. **Редактирование сообщений** - уведомления об изменении сообщений (с пометкой [EDITED])
3. **Голосовые события** - уведомления о подключении/отключении отслеживаемых пользователей к голосовым каналам
   - 🎤 Подключение к голосовому каналу
   - 🔇 Отключение от голосового канала
   - Переход между каналами (считается как подключение)

## 🔍 Формат уведомлений

### Сообщения:
Уведомления о сообщениях в Telegram содержат:
- Время сообщения
- Название сервера
- Название канала
- Автор (username#discriminator и ID)
- Текст сообщения
- Ссылка на сообщение
- Вложения (ссылки на файлы)

Пример:
```
🔔 Новое сообщение
📅 Время: 2024-01-15 14:30:00
🏷 Сервер: My Server
📺 Канал: general
👤 Автор: User#1234 (123456789012345678)
💬 Сообщение: Привет всем!
🔗 Ссылка: https://discord.com/channels/...
```

### Голосовые события:
Уведомления о подключении/отключении к голосовым каналам:
- Время события
- Название сервера
- Название голосового канала
- Пользователь (username#discriminator и ID)
- Тип события (подключение/отключение)

Пример подключения:
```
🎤 Подключился к голосовому каналу
Канал: General Voice
Сервер: My Server
```

Пример отключения:
```
🔇 Покинул голосовой канал
Канал: General Voice
Сервер: My Server
```

## 🧪 Тестирование

### Ручное тестирование:
1. Запустите приложение
2. Введите Telegram Chat ID
3. Добавьте Discord ID пользователя для отслеживания
4. Добавьте Guild ID сервера для отслеживания
5. Нажмите "Сохранить конфиг"
6. Нажмите "Start Bot"
7. Отправьте сообщение в отслеживаемом канале от отслеживаемого пользователя
8. Проверьте получение уведомления в Telegram

### Проверка логов:
- Логи сохраняются в `log.txt`
- Просмотр через кнопку "Просмотр логов" в GUI

## ⚠️ Предупреждения

1. **Использование Userbot**: Нарушает ToS Discord. Используйте на свой риск.
2. **Токены**: Никогда не публикуйте токены в публичных репозиториях.
3. **Rate Limits**: Telegram и Discord имеют ограничения на количество запросов.
