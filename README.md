# Discord → Telegram Notification App

Приложение для пересылки уведомлений из Discord в Telegram с использованием **Userbot** (самобот). Работает как локальное приложение с GUI на Tkinter.

## ⚠️ Важное предупреждение

**Использование userbot (самоботов) нарушает Условия использования Discord.** Используйте на свой страх и риск. Аккаунт может быть заблокирован. Для.production-среды рекомендуется использовать официальный Discord Bot API.

---

## 📋 Возможности

### Отслеживаемые события:
1. **Сообщения** - пересылка сообщений от отслеживаемых пользователей в отслеживаемых серверах
2. **Голосовые события** - уведомления о подключении/отключении пользователей к голосовым каналам

### Функции:
- ✅ GUI с тёмной темой
- ✅ Форма для ввода токенов (.env) прямо в интерфейсе
- ✅ Добавление/удаление tracked пользователей (по Discord ID)
- ✅ Добавление/удаление tracked серверов (по Guild ID)
- ✅ Настройка Telegram Chat ID через GUI
- ✅ Фильтр по упоминаниям владельца
- ✅ Фильтр по ключевым словам
- ✅ Включение/отключение отслеживания голосовых событий
- ✅ Сохранение конфигурации в JSON
- ✅ Просмотр логов в отдельном окне
- ✅ Кнопки Start/Stop бота

## 🔧 Установка

### 1. Клонирование/создание файлов
Убедитесь, что все файлы находятся в одной директории:
```
├── main.py              # Точка входа, GUI
├── bot_worker.py        # Логика Discord бота
├── telegram_client.py   # Отправка в Telegram
├── config_manager.py    # Управление конфигом и логами
├── requirements.txt     # Зависимости
├── config.json          # Конфигурация (создаётся автоматически)
└── .env.sample          # Шаблон переменных окружения
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Получение токенов

#### Discord User Token
1. Откройте Discord в браузере (Chrome/Firefox)
2. Войдите в свой аккаунт
3. Откройте DevTools (F12)
4. Перейдите во вкладку **Network**
5. Обновите страницу (F5)
6. Найдите запрос к `api.discord.com`
7. В заголовках найдите `Authorization` - это ваш токен
8. **Скопируйте токен** (начинается с `mfa.` или длинной строки)

⚠️ **Никогда не передавайте свой токен никому!**

#### Telegram Bot Token
1. Откройте @BotFather в Telegram
2. Создайте нового бота командой `/newbot`
3. Следуйте инструкциям
4. Скопируйте полученный токен

#### Telegram Chat ID (ваш ID)
1. Откройте @userinfobot в Telegram
2. Нажмите Start
3. Бот пришлёт ваш ID (число)

#### Discord Owner ID (ваш Discord ID)
1. В Discord включите режим разработчика: Настройки → Дополнительно → Режим разработчика
2. Кликните ПКМ по своему имени
3. Выберите "Копировать ID"

## 🚀 Запуск

### 1. Первый запуск
```bash
python main.py
```

### 2. Настройка через GUI
1. Введите Discord Token и Telegram Bot Token в разделе "🔐 Настройки .env"
2. Нажмите "💾 Сохранить .env"
3. Введите ваш Telegram Chat ID в разделе "📱 Telegram Настройки"
4. Введите ваш Discord Owner ID в разделе "🎮 Discord Настройки"
5. Добавьте tracked пользователей (их Discord ID)
6. Добавьте tracked сервера (их Guild ID)
7. Настройте фильтры при необходимости
8. Нажмите "💾 Сохранить конфиг"
9. Нажмите "▶️ Start Bot"

## 🔍 Фильтры

### Только упоминания владельца
Если включено - пересылаются только сообщения, где упомянут владелец (Discord Owner ID)

### Ключевые слова
Если заданы - пересылаются только сообщения, содержащие указанные слова

### Голосовые события
Можно включить/отключить отслеживание подключений к голосовым каналам

## 🛠️ GuildSubscriptionOptions (вместо Intents)

Приложение использует `discord.py-self`, который работает с токеном пользователя, а не бота. Вместо системы Intents (как у обычных ботов), здесь используется `GuildSubscriptionOptions`.

### GuildSubscriptionOptions.default():
- **auto_subscribe: True** - автоматическая подписка на события гильдий
- **concurrent_guilds: 2** - количество одновременных подключений к гильдиям

Userbot автоматически получает доступ ко всем событиям, которые видит обычный клиент Discord:
- ✅ Сообщения во всех каналах
- ✅ Голосовые события (подключения/отключения)
- ✅ Информация о пользователях и серверах
- ✅ Содержимое сообщений (не требует отдельного разрешения)

**Важно:** В отличие от официальных ботов, userbot не требует настройки intents в панели разработчика Discord, так как использует токен обычного пользователя.

## 🧪 Тестирование

### Ручное тестирование:
1. Запустите приложение
2. Сохраните токены и настройки
3. Добавьте свой Discord ID в tracked users
4. Добавьте сервер в tracked guilds
5. Запустите бота
6. Отправьте сообщение на отслеживаемом сервере
7. Проверьте получение уведомления в Telegram

### Проверка голосовых событий:
1. Убедитесь, что "Отслеживать голосовые события" включено
2. Подключитесь к голосовому каналу на отслеживаемом сервере
3. Проверьте уведомление в Telegram

## 📌 Примечания

1. **Userbot vs Bot**: Это приложение использует токен пользователя (userbot), а не официального бота Discord. Это даёт больше возможностей, но нарушает ToS Discord.

2. **Библиотека**: Используется `discord.py-self` - форк discord.py с поддержкой userbot.

3. **Безопасность**: Токены хранятся в локальном файле `.env`. Не передавайте этот файл другим лицам.

4. **Производительность**: Приложение работает асинхронно и не должно значительно нагружать систему.

## 🆘 Решение проблем

### Бот не запускается
- Проверьте правильность токенов
- Убедитесь, что Discord токен действителен (не истёк)
- Проверьте логи (`log.txt`)

### Не приходят уведомления
- Проверьте Telegram Chat ID
- Убедитесь, что tracked users/guilds добавлены
- Проверьте фильтры (возможно, они слишком строгие)

### Ошибка "Telegram error"
- Проверьте токен бота Telegram
- Убедитесь, что бот не заблокирован
