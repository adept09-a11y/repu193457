# Discord → Telegram Notification App

Приложение для пересылки уведомлений из Discord в Telegram с использованием **Userbot** (работает от имени вашего аккаунта Discord).

## 🚀 Возможности

- **Отслеживание сообщений**: Пересылка сообщений от указанных пользователей на указанных серверах
- **Голосовые события**: Уведомления о подключении/отключении пользователей к голосовым каналам
- **Редактирование сообщений**: Отслеживание изменений в сообщениях
- **Фильтры**: 
  - Только упоминания владельца
  - Ключевые слова
  - Выбор конкретных пользователей и серверов
- **Тёмная тема GUI**: Удобный интерфейс для управления настройками
- **Логирование**: Все действия записываются в `log.txt`

## 📋 Требования

- Python 3.8+
- Windows/Linux/macOS с графическим интерфейсом (для работы GUI)

## 🔧 Установка

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

**Важно:** Используется библиотека `discord.py-self` (форк discord.py для userbot). Не устанавливайте обычную `discord.py` — возникнет конфликт!

Если возникают проблемы с установкой:
```bash
pip uninstall -y discord.py discord.py-self
pip cache purge
pip install "discord.py-self>=1.9.2"
```

### 2. Получение токенов

#### Discord Token (Userbot)

⚠️ **Предупреждение:** Использование userbot может нарушать условия использования Discord. Используйте на свой страх и риск!

1. Откройте Discord в браузере (Chrome/Firefox)
2. Нажмите F12 для открытия DevTools
3. Перейдите на вкладку **Network**
4. Обновите страницу Discord
5. Найдите запрос к `api.discord.com`
6. В заголовках запроса найдите `Authorization`
7. Скопируйте значение — это ваш токен

Или используйте готовые инструменты для получения токена (ищите "get discord token" в GitHub).

#### Telegram Bot Token

1. Откройте Telegram и найдите [@BotFather](https://t.me/botfather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен

#### Telegram Chat ID

1. Запустите созданного бота (нажмите `/start`)
2. Отправьте боту сообщение
3. Откройте URL: `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
4. Найдите `"chat":{"id":123456789}` — это ваш Chat ID

Для личных сообщений используйте ваш числовой ID (положительное число).

## ⚙️ Настройка через GUI

### 1. Настройки .env (токены)

- **Discord Token**: Токен вашего аккаунта Discord
- **Telegram Bot Token**: Токен Telegram бота
- Нажмите **"💾 Сохранить .env"** для сохранения

### 2. Telegram Настройки

- **Telegram Chat ID**: ID чата или пользователя, куда отправлять уведомления
- Нажмите **"🧪 Тест соединения"** для проверки

### 3. Discord Настройки

- **Discord Owner ID**: Ваш Discord ID (для фильтра упоминаний)
  - Как получить: В Discord включите режим разработчика (Настройки → Дополнительно), затем ПКМ по себе → Копировать ID

### 4. Отслеживаемые пользователи

Добавьте Discord ID пользователей, за которыми хотите следить:
- Введите ID в поле
- Нажмите **"➕ Добавить"**
- Для удаления выберите пользователя и нажмите **"➖ Удалить выбранного"**

### 5. Отслеживаемые сервера

Добавьте Guild ID серверов для мониторинга:
- Введите ID сервера
- Нажмите **"➕ Добавить"**
- Оставьте пустым для отслеживания на всех серверах

### 6. Фильтры

- **Только упоминания владельца**: Пересылать только сообщения с упоминанием вас
- **Отслеживать голосовые события**: Включить уведомления о голосовых подключениях
- **Ключевые слова**: Пересылать только сообщения containing эти слова

## 📡 Отслеживаемые события

### Сообщения
- Новые сообщения от отслеживаемых пользователей
- Редактирование сообщений

### Голосовые события
- Подключение к голосовому каналу 🎤
- Отключение от голосового канала 🔇
- Переход между каналами 🔄

## ⚠️ Важные замечания

### Message Content Intent

Для получения содержимого сообщений в некоторых случаях требуется включить **Message Content Intent**:

1. Зайдите в [Discord Developer Portal](https://discord.com/developers/applications)
2. Выберите ваше приложение (если есть)
3. Перейдите в раздел **Bot**
4. Включите **Message Content Intent**

Для userbot это обычно не требуется, но зависит от конфигурации сервера.

### Права доступа

Userbot работает от имени вашего аккаунта, поэтому имеет те же права, что и вы:
- Чтение сообщений на серверах, где вы состоите
- Просмотр списка участников
- Отслеживание голосовых событий

### Ограничения

- Не используйте на очень больших серверах (>100k участников) — могут быть задержки
- Discord может ограничить аккаунт при подозрительной активности
- Делайте перерывы в работе бота

## ❓ Решение проблем

### Ошибка `No module named 'cgi'`

Проблема с версией Python 3.13 и старой версией aiohttp:
```bash
pip install --upgrade aiohttp
```

### Ошибка `GuildSubscriptionOptions`

Убедитесь, что установлена именно `discord.py-self`, а не `discord.py`:
```bash
pip uninstall -y discord.py discord.py-self
pip install "discord.py-self>=1.9.2"
```

### Бот не отправляет сообщения в Telegram

1. Проверьте токен бота
2. Проверьте Chat ID (должен быть числом)
3. Убедитесь, что бот запущен (нажмите /start в Telegram)
4. Используйте кнопку **"Тест соединения"** в GUI

### Userbot не подключается

1. Проверьте токен Discord (он мог истечь)
2. Убедитесь, что токен скопирован полностью без пробелов
3. Попробуйте получить новый токен
