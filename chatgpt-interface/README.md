# ChatGPT Multi-Account Interface

Приложение-посредник для работы с множеством аккаунтов ChatGPT с быстрым переключением между ними и сохранением промтов.

## 🚀 Возможности

### Управление аккаунтами
- **Множество аккаунтов**: Добавляйте неограниченное количество аккаунтов OpenAI/Anthropic/Custom API
- **Быстрое переключение**: Переключайтесь между аккаунтами в один клик
- **Поиск аккаунтов**: Горячие клавиши `Ctrl/Cmd+K` для быстрого поиска и переключения
- **Безопасное хранение**: API ключи шифруются с использованием Web Crypto API (AES-GCM)
- **Тестирование подключения**: Проверка работоспособности каждого аккаунта

### Шаблоны промтов
- **Сохранение промтов**: Создавайте и храните библиотеку часто используемых промтов
- **Быстрая вставка**: Вставляйте шаблоны в чат одним кликом
- **Экспорт/Импорт**: Сохраняйте шаблоны в JSON и делитесь ими
- **Редактирование**: Обновляйте и удаляйте шаблоны

### Чат
- **Прямая интеграция с API**: Отправка запросов напрямую к OpenAI API
- **Поддержка нескольких провайдеров**: OpenAI, Anthropic, Custom endpoints
- **История сообщений**: Просмотр текущей сессии чата
- **Горячие клавиши**: `Ctrl/Cmd+Enter` для отправки сообщения

## 🛠️ Технологии

- **Frontend**: React + TypeScript + Vite
- **Хранение данных**: LocalForage (IndexedDB)
- **Шифрование**: Web Crypto API (AES-GCM)
- **Стили**: Inline CSS


## 🔐 Безопасность

- API ключи шифруются перед сохранением в браузере
- Ключ шифрования хранится в localStorage
- Расшифровка происходит только в момент отправки запроса
- Все данные хранятся локально в браузере (IndexedDB)

## 💡 Использование

### Добавление аккаунта
1. Нажмите кнопку **"Manage"** в хедере
2. В открывшемся модальном окне нажмите **"Add New Account"**
3. Введите:
   - Название аккаунта (например, "Work", "Personal")
   - API ключ OpenAI
   - Выберите провайдера (OpenAI/Anthropic/Custom)
4. Нажмите **"Add Account"**

### Быстрое переключение
- Используйте выпадающий список в хедере
- Или нажмите **"⚡ Quick Switch"** (`Ctrl/Cmd+K`)
- Начните вводить название аккаунта для поиска

### Создание шаблона
1. Откройте панель шаблонов справа
2. Нажмите **"+ New"**
3. Введите название и содержание шаблона
4. Используйте `{{placeholder}}` для переменных
5. Нажмите **"Create"**

### Использование шаблона
- Нажмите кнопку **"Insert"** рядом с нужным шаблоном
- Шаблон автоматически вставится в поле ввода чата

## 🌐 Поддерживаемые провайдеры

- **OpenAI**: Полная поддержка через api.openai.com
- **Anthropic**: Базовая поддержка (требует дополнительной настройки)
- **Custom**: Любые совместимые API endpoints
