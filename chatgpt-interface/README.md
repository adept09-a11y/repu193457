# ChatGPT Interface - Frontend-Only MVP

Веб-интерфейс для работы с ChatGPT и другими AI-провайдерами с поддержкой множественных аккаунтов и шаблонов промтов.

## Технологии

- **React 18** + **Vite** + **TypeScript**
- **IndexedDB** (через localforage) для локального хранения данных
- **Web Crypto API** для шифрования API-ключей
- **CSS-in-JS** (inline styles) для минималистичного дизайна

## Функции

### Управление аккаунтами
- ✅ Добавление/редактирование/удаление аккаунтов
- ✅ Поддержка OpenAI, Anthropic и custom-провайдеров
- ✅ Кнопка "Test connection" для проверки API-ключа
- ✅ Быстрое переключение между аккаунтами (Ctrl/Cmd+K)
- ✅ Поиск по аккаунтам в sidebar

### Шаблоны/Prompts
- ✅ CRUD шаблонов с placeholder'ами вида `{{name}}`
- ✅ Быстрая вставка шаблона в поле ввода (один клик)
- ✅ Импорт/экспорт шаблонов (JSON)

### Отправка запросов
- ✅ Поле ввода prompt + кнопка отправить
- ✅ Отправка по Ctrl/Cmd+Enter
- ✅ Отображение ответов в чате
- ✅ Поддержка разных провайдеров (OpenAI, Anthropic, Custom)

### Безопасность
- ✅ API-ключи хранятся зашифрованными в IndexedDB
- ✅ Используется AES-GCM шифрование через Web Crypto API
- ✅ Данные не покидают браузер

## Установка

```bash
cd chatgpt-interface
npm install
npm run dev
```

## Сборка для production

```bash
npm run build
```

Результат будет в папке `dist/`.

## Структура проекта

```
chatgpt-interface/
├── src/
│   ├── App.tsx           # Главный компонент приложения
│   ├── Chat.tsx          # Компонент чата
│   ├── AccountForm.tsx   # Форма добавления/редактирования аккаунта
│   ├── TemplateForm.tsx  # Форма добавления/редактирования шаблона
│   ├── hooks.ts          # React хуки для работы с данными
│   ├── db.ts             # Работа с IndexedDB и шифрование
│   ├── types.ts          # TypeScript типы
│   ├── main.tsx          # Точка входа
│   └── index.css         # Глобальные стили
├── index.html
├── package.json
├── tsconfig.json
└── vite.config.ts
```

## Горячие клавиши

- **Ctrl/Cmd+K** - Фокус на селектор аккаунтов для быстрого переключения
- **Ctrl/Cmd+Enter** - Отправить сообщение

## Ограничения MVP

- ⚠️ API-ключи расшифровываются в памяти браузера при использовании
- ⚠️ CORS может блокировать прямые вызовы к некоторым API
- ⚠️ Нет истории сообщений между сессиями
- ⚠️ Мастер-пароль упрощён (для полноценной версии нужно добавить экран установки пароля)
